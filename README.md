# Arduino入門講座 第3回「パソコンから無線でサーボモーターを動かそう」教材

Arduino UNO R4 WiFi 用の教材です。ZIPをダウンロードしたら、必ず展開してから使います。
（これまでと同じ手順：このページの「Code」→「Download ZIP」→ 右クリック「すべて展開」）

> 【状態】新規作成の教材です。代替環境でのコンパイルと、操作ページの模擬テストだけ確認しています。
> 実機（UNO R4 WiFi・サーボ・Chrome の Bluetooth 接続）での確認は、授業前に講師が行います。

## 入っているもの

| ファイル・フォルダー | 内容 | 時間 |
|---|---|---|
| `dai3_1_servo_sweep` | サーボを 0° から 180° まで少しずつ動かし、0° へ戻す（往復をくり返す）。① ホーンを付ける前に動くことを確かめる ④ ホーンを付けたあと、ホーンの往復を確かめる | 1時間目 |
| `dai3_1_servo_90` | サーボを 90° に動かして止める。② この位置でホーンを取り付ける（`servo.write(90);` の数字を変えると角度が変わる） | 1時間目 |
| `dai3_2_servo_ble` | 操作ページのボタンで、サーボと LED マトリクスを動かす | 2・3時間目 |
| `index.html` | 操作ページ。展開したフォルダーの中のこのファイルを、PC の Google Chrome で開く | 2・3時間目 |

## 1時間目の進め方

1. `dai3_1_servo_sweep` を書き込む（ホーンなし）→ 軸が往復するのを目で確かめる
2. `dai3_1_servo_90` を書き込む → 軸が 90° で止まるのを確かめる
3. USB を抜いて電源を外し、90° の軸にホーンを中央の向きで取り付ける
4. もう一度 `dai3_1_servo_sweep` を書き込む → ホーンが 90° を通って両側へ往復するのを確かめる

## 配線（すべてのスケッチで同じ。途中で変えない）

| サーボの線 | Arduino のピン |
|---|---|
| 信号（キットのサーボでは、ふつうオレンジ） | D9 |
| 電源 ＋（ふつう赤） | 5V |
| GND −（ふつう茶） | GND |

- 線の色はサーボによって違うことがあります。色だけで決めず、資料の図と実物で確かめます。
- 配線を変えるときは、必ず電源（PC の USB・別の電源）を外してから行います。
- 3.3V にはつなぎません。サーボに重い物を付けません。
- 5V ピンからの給電は、講師が使用するサーボで事前に確認した構成です。動作が不安定なとき（リセットする・震える）は、講師に知らせてください。

## dai3_2_servo_ble で変えるところ（「★ここを変える」の中だけ）

| 名前 | 初めの値 | 意味 |
|---|---|---|
| `DEVICE_NAME` | `"NGS-01"` | 機器名。先生から割り当てられた自分の番号にする（NGS-01〜NGS-11）。番号と機器名は紙に書いて Arduino の横に置く |
| `LEFT_ANGLE` | `0` | 「◀ 左」ボタンの角度 |
| `CENTER_ANGLE` | `90` | 「● 中央」ボタンの角度 |
| `RIGHT_ANGLE` | `180` | 「右 ▶」ボタンの角度 |
| `PICTURE_LEFT` など | 矢印・丸 | LED マトリクスの絵（`#` が光る、`.` が消える。横12文字×縦8行） |

## 使うときのきまり

- 書き込むとき：PC と Arduino を USB でつなぐ（書き込みと電源）。
- 無線で操作するとき：PC と Arduino の USB ケーブルを外し、Arduino の USB 端子を別の電源（USB モバイルバッテリー、または USB AC アダプター）につなぐ。LED に番号が出てから、PC の Chrome で index.html を開き、Bluetooth で接続する。
- 電源をつなぎかえると Arduino は起動し直す（書き込んだプログラムは消えない）。Bluetooth の接続は、つなぎかえたあとに行う。
- サーボの電源は、これまでどおり Arduino の 5V・GND から取る。
- コードを直すとき：「切断」→ 別の電源から外す → PC と USB でつなぐ → 直して書き込む → PC の USB を外して別の電源につなぐ → 接続し直す → 確かめる。
- Bluetooth の設定画面（Windows の設定、macOS のシステム設定）でペアリングする必要はありません。
  操作ページの「Bluetoothで接続」を押し、Chrome が出す一覧から自分の機器を選びます。
- 接続を待っている間、LED マトリクスに機器名の番号（例：01）が出ます。
- 送る文字：L（左）・C（中央）・R（右）。Arduino は「L:0:NGS-01」のように返事をします。
- 予備：シリアルモニター（9600）から L・C・R を送っても動きます。
- 操作ページは外部のライブラリを読み込みません（インターネットがなくても画面は動く作り）。
